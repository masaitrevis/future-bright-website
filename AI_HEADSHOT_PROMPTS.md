## Quick Start: Midjourney

1. Go to [discord.com](https://discord.com) → Midjourney server
2. Type `/imagine` + paste any prompt above
3. Hit enter, wait ~30 seconds
4. Upscale the best result (U1, U2, U3, or U4)
5. Download and save with the filename above

## Quick Start: DALL-E 3 (ChatGPT Plus)

1. Open ChatGPT with Plus subscription
2. Use GPT-4 with DALL-E
3. Paste the prompt (remove `--ar 1:1 --v 6` at the end)
4. Ask it to generate
5. Download and save

---

## Tips for Best Results

- **Remove `--ar 1:1 --v 6`** if using DALL-E or Leonardo (those are Midjourney-specific)
- **If the face looks too generic**, add: "distinctive facial features, unique individual"
- **If the background is wrong**, add: "plain solid dark navy background, no gradients, no patterns"
- **If the expression is too serious**, add: "warm approachable smile, friendly expression"

---

## Fallback: Same Person, Multiple Angles

If you want to generate multiple options for one person quickly, add this to any prompt:
> "Generate 4 variations: slight smile, neutral expression, confident pose, relaxed pose"

Then pick the best one.
